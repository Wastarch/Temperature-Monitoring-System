# 虚拟串口温度数据发送器
模拟多通道温度传感器，通过虚拟串口按自定义协议循环发送温度数据。配合上位机调试和协议验证。
## 快速开始

**安装依赖(推荐使用uv)**
```bash
uv sync
```
或
```bash
 uv add pyserial
```

**运行（需先创建虚拟串口对）**
```bash
uv run main.py
```
## 配置
修改 `main.py` 顶部常量：
| 常量       | 默认值      | 说明           |
| ---------- | ----------- | -------------- |
| `PORT`     | `COM10`     | 串口号         |
| `BAUD`     | `9600`      | 波特率         |
| `INTERVAL` | `1.0`       | 发送间隔（秒） |
| `CHANNELS` | `[1, 2, 3]` | 发送的通道列表 |
## 功能
- [x] 8 通道支持（1~8）
- [x] 温度范围 -10.0°C ~ 50.0°C
- [x] 多通道数据合并在同一帧发送
- [x] XOR 校验
- [x] 循环持续发送
## 运行示意
```
已打开串口 COM10，波特率 9600，按 Ctrl+C 停止发送
[发送] 3通道 CH1：25.5°C CH2：-3.1°C CH3：100.0°C -> AA 03 01 00 FF 02 FF E1 03 03 E8 09 0A
[发送] 3通道 CH1：30.1°C CH2：47.0°C CH3：-8.4°C -> AA 03 01 01 2D 02 01 D6 03 FF AC D5 0A
```
按 `Ctrl+C` 停止发送并关闭串口。
## 通信协议
详细协议文档见 [`PROTOCOL.md`](PROTOCOL.md)。
| 参数          | 值   |
| ------------- | ---- |
| 波特率        | 9600 |
| 数据位        | 8    |
| 校验位        | None |
| 停止位        | 1    |
| 帧结构：`0xAA | N    | CH1_DATA...CHn_DATA | XOR | 0x0A` |
## 测试方式
使用虚拟串口软件（如 VSPD、com0com）创建串口对，将本程序发送端连到一个 COM 口，上位机串口助手监听另一个 COM 口。
